# 多観点判定の実装・検証

対象: ナイモノ研究所、判定方式 `multi-angle-v3`。公開サイトへのデプロイは未実施。

## 変更

- 全体の聞き覚え、日常語、バンド・人名、作品・キャラクター、地名・商品、専門用語、読み・表記違いの7観点をJevのNoulで評価する。
- 未知の固有名詞や専門語を見落とす注意度を、5段階のScoreで評価して「名前かも」として表示する。
- 最大の既存語スコアが85以上ならアウト。全観点20以下かつ「名前かも」45未満ならセーフ。それ以外は家族の確認。平均や確率の積で独立した証拠が増えたとは扱わない。
- 表記は保存時も変更せず、機械的なひらがな・カタカナ変換を同じ語の手がかりとして添える。任意の訂正や漢字の読み生成は行わない。
- 各スコア、最大の観点、判定基準を結果画面に常時表示する。手動で勝敗を変更しても元のAIスコアを残す。
- カテゴリーに加えて「語感」のChoiceを取得し、発見と図鑑に表示・保存する。想像の個性は存在判定に使わない。
- 1回のAI呼び出しに質問をまとめる。既存のレート制限・タイムアウト・設定・認証範囲は変更していない。

## 検証結果

- `npm test`: 50件成功。バンドだけ高い場合、未知の名前の確認、境界値、不正・欠落回答、カテゴリー・語感の独立性、表記変換、HTTPとWorkerの経路を含む。
- `npm run build`: 単体HTMLの生成成功。
- `scripts/browser_smoke.py`: 87項目成功。7観点の展開表示、手動訂正後のスコア維持、語感の保存と再読込、320 / 390 / 768 / 1360pxでの横はみ出しを検証。音声認識はモック。
- ローカルWranglerからリモートの実Jev `jev-1.13.0` を実行。中間方式v2の18語では既存語11件がアウト9・確認2・誤セーフ0、検証用造語4件がセーフ1・確認3・アウト0だった。この結果は最終v3の全体精度を示さない。
- 最終v3で表記違いを含む8語を追加確認。既存名4件、検証用造語4件はすべて確認判定。`よるしか` はバンド名の観点で84/100を返した。別の実ブラウザ確認では78/100で、同じ入力でも数値の揺れがある。
- 最終v3の実ブラウザから実Jevへ2語を送り、スコア表示と、家族確認後の発見・語感保存・ネイティブlocalStorageからの再読込を確認。JavaScriptエラー0。

## 限界

Jevの判断を複数の観点から得る実装であり、外部検索による実在確認ではない。一般的な日本語精度の改善率は測定していない。未知の固有名詞を誤セーフにしにくくする一方、今回の最終検証では造語にも確認が多く、遊ぶ人の判断が必要になる。スコアの閾値はこのゲームの運用ルールであり、較正済みの存在確率ではない。

バンド名の検証用出典: [ヨルシカ公式](https://yorushika.com/)、[サカナクション公式](https://sakanaction.jp/)、[MAN WITH A MISSION公式](https://www.mwamjapan.info/)、[マカロニえんぴつ公式](https://macaroniempitsu.com/)。
