しりとりのやくそく

さいごの音からつなぎます。「ん」で終わったら負け。同じことばも使えません。小さい文字は大きくしてつなぎます（「ゃ」→「や」）。最後の「ー」は飛ばします（「ぴょもー」→「も」）。濁点・半濁点はそのままです。

「ある」のは、もの？ ことば？

このゲームでは、すでに知られていることばや名前なら「ある」。だから「ドラゴン」や、有名なキャラクターの名前もアウトです。新しく作ったことば全体で判定します。

つぎはぎ・文章も、アウト寄り。

「宇宙＋バナナ」のように、意味のあることばをつないだだけの名前や、「ねこが空を飛ぶ」のような文章・説明もアウト。「もにゅらっぴ」のような、新しい響きを考えてみよう。一部の音が似ているだけでは、つぎはぎにしません。はっきりしないときは、みんなで決めよう。

まちがっても、だいじょうぶ。

漢字・カタカナは、聞き取った文字のまま判定できます。聞きまちがいだけ直してね。Jev接続中は、しりとりの最初と最後の音も自動で確認。読みがわからないときだけ、よみかたを教えてね。時間は考えている間だけ。文字の確認・通信中は止まります。Jevは世界中を検索する辞書ではなく、間違えることもあります。「ちょっと待った！」から、みんなで判定を直せます。

音声入力では、ブラウザの音声認識サービスへ音声が送られる場合があります。このアプリ自身は録音しません。Jevモードでは、確定したことば・読み・あそびかたをCloudflare Workers AI経由でJevへ送り、判定と分類を行います。図鑑はこのブラウザだけに保存し、いつでも消せます。プレイヤー名はサーバーへ送りません。

Jevであそぶには

Cloudflareにログインした状態で、WranglerからWorkers AI bindingを使います。TypeSafeのAPIキーをブラウザやソースに設定する必要はありません。

npx wrangler dev

公開するときは npx wrangler deploy。この画面のAPIは同じWorker内の env.AI からJevを呼びます。単体HTMLと npm start はおためし辞書です。

おためし版の判定について

付属の小さな辞書にあることばはアウト。載っていないことばは、みんなで決めます。未知語をAIで調べたふりはしません。

Jevの数値はモデルの判断であり、本当の「存在確率」ではありません。日本語の判定精度は実際の判定ログで確認します。誤判定は家族の合意で直してあそんでください。
